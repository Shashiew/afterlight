AFTERLIGHT // SIGNAL SALVAGE
===========================

A self-contained neon arcade survival game. No installs, accounts, internet, or external libraries needed.

HOW TO PLAY
-----------
1. Extract the ZIP if you downloaded the package.
2. Double-click afterlight.html to open it in a modern desktop browser.
3. Click ENTER THE DRIFT.

CONTROLS
--------
W / A / S / D or Arrow Keys : Move
Mouse                       : Aim
Hold Left Mouse Button      : Fire
J or Space                  : Fire
Shift                       : Dash (brief invulnerability)
E                           : Pulse blast (damages nearby hostiles and clears enemy shots)
Esc                         : Pause / resume
M                           : Toggle synthesized sound effects

GAMEPLAY
--------
- Collect cyan signal fragments to level up.
- Choose one of three upgrades whenever you level up.
- Different hostiles behave differently; the Warden arrives after 40 seconds and returns later.
- Your personal best is saved in this browser using localStorage.
